# Changelog

## 1.1.0
- Floating panel can now add Key, Type text and Wait steps without opening the app (form shown on top of your game).
- Floating panel: Undo last step, step counter, clearer labels.
- New AutoStep Keyboard: full QWERTY (letters, numbers, symbols, shift, enter, backspace) so you can type in forms too.
- Simpler step form: seconds instead of milliseconds, quick preset buttons, advanced options collapsed.
- Onboarding: welcome dialog, Help screen, step-by-step guide for "Restricted setting" with an "Open App info" button.
- Home screen simplified: Run button and steps first, setup cards below once accessibility is on.
- Crash reporter screen (copy the error into a bug report).
- Fix: crash on Android 14 when checking whether the keyboard is enabled.
- Release workflow: tag `vX.Y.Z` builds an APK and a SHA256SUMS file.

## 1.0.0
- Initial version: tap, random tap, hold (incl. forever), swipe, key, text, wait; floating Run/Stop; coordinate picker.
